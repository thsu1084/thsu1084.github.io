SetPieceRAG

Domain-Specific RAG for Knowledge-Intensive Soccer VQA with Large Language Models

Youngseon Kim · Jongmin Lee
Chung-Ang University
Paper ↗ Poster ↗ Code · Coming Soon

Abstract

Visual Question Answering (VQA) in the soccer domain extends beyond simple visual queries and is an important step toward comprehensive sports video understanding. SetPieceRAG is a domain-specific Retrieval-Augmented Generation (RAG) framework tailored for soccer. In addition to the core RAG mechanism, the method incorporates task-specific adaptations including LLM ensembling, LoRA-based domain fine-tuning, super-resolution preprocessing, and object-centric analysis via SAHI.

For knowledge-intensive queries, SetPieceRAG integrates vision-language tools such as CLIP with external knowledge sources, including a domain-specific corpus (SoccerWiki) and web-search capabilities of Multimodal Large Language Models (MLLMs). This provides non-parametric and long-tail knowledge that is not reliably available in either Large or Small Language Models. By retrieving and injecting the required external knowledge, the framework improves retrieval and answer generation on SoccerNet VQA.

Method

The proposed pipeline separates visual grounding from language generation. A frozen CLIP visual encoder extracts image features, which are normalized and used as query vectors for a FAISS index. The retrieved visual matches are used to identify the target entity, and the corresponding textual knowledge is then supplied to the language model as external context.

01

CLIP Visual Encoder

CLIP ViT-B/32 extracts global visual representations from the input image for retrieval rather than direct token-level fusion with an LLM.

02

FAISS Retrieval

L2-normalized visual embeddings are matched against an indexed reference corpus to identify the relevant soccer entity.

03

Knowledge-Conditioned Generation

The retrieved entity is linked to textual knowledge, which is injected into the language-model prompt together with the question and answer choices.

LLM cascade

The system uses a hierarchical language-model cascade. A local LLaMA 3.2 1B model serves as the first response generator. When the expected answer format is not produced, when retrieved context is unavailable, or when an internal failure occurs, the system falls back to Gemini with Google Search to access up-to-date external information. The final output is normalized into the required answer label format through an extractor module.

Task-Specific Adaptation

Because SoccerNet VQA contains heterogeneous tasks, the paper groups them by the capability they require and applies dedicated pipelines rather than a single uniform model.

CategoryPaper configurationTarget tasks / purpose
Vision-Language Foundation & Ensemble Gemini-based multimodal reasoning and LLM ensemble Multi-view foul, jersey-color relevant QA, replay grounding, and text-based QA.
Retrieval-Augmented & Knowledge-Integrated RAG with retrieved database context and knowledge extraction Commentary-relevant QA, action classification, and background-image knowledge QA.
Domain-Specific Fine-tuning & Super-Resolution LoRA-based adaptation and super-resolution preprocessing Camera-status tasks and recognition-heavy tasks such as jersey number and score/time QA.

Experimental Setting

The method is evaluated on SoccerBench and the test/challenge splits of the 2026 SoccerNet Visual Question Answering challenge. SoccerBench covers text, image, and video inputs across 13 soccer-analysis tasks with approximately 10,000 multiple-choice QA pairs. The 2026 challenge adds Game State QA, expanding the benchmark to 14 tasks. Accuracy is used as the evaluation metric following the official challenge protocol.

Training and inference were conducted in Google Colab Pro+ with an NVIDIA A100 GPU.

What the Paper Demonstrates

The paper shows that soccer VQA benefits from combining domain-specific retrieval with task-specific adaptation. In particular, external knowledge is used to address knowledge-intensive questions, while LoRA, super-resolution, model ensembling, and object-centric analysis target the distinct bottlenecks of other task categories. The reported experiments demonstrate improved retrieval performance and accurate answer generation on SoccerNet VQA.
